# Portfólio de Rui Granja (UX/UI Designer & CRO Specialist)

Portfólio profissional e currículo interativo de Rui Granja, com estudos de caso de projetos, experiência profissional, educação e suporte para modo claro e escuro.

🌐 **Site em produção:** [https://ruigranja.vercel.app/](https://ruigranja.vercel.app/)

---

## 🛠️ Stack Tecnológica

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Motion** (Framer Motion)

---

## 🚀 Setup Local

### Pré-requisitos
- Node.js (v18+)
- npm

### Comandos

1. **Instalar dependências:**
   ```bash
   npm install
   ```

2. **Iniciar em modo de desenvolvimento:**
   ```bash
   npm run dev
   ```

---

## 📦 Build de Produção

Para gerar a compilação otimizada para produção:

```bash
npm run build
```

Os ficheiros compilados serão guardados no diretório `dist/`.
